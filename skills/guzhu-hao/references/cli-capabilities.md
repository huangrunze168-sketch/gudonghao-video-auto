# 官方能力地图：证据分级

旧版“192/192 可用”“material 全域不可用”“net_counts 证明联网”“13 个模板全因缺字体”等结论已撤销。

## 可以确认

- 当前清单含 195 条命令路径，封装为 177 个清单函数和 18 个手写函数。手写函数签名不同，不能全部套 `(cwd, ref, options)`。
- 官方在线贴纸及字体搜索已真实返回 `err_code=0` 和资源元数据。
- 官方贴纸及字体下载已真实返回 `err_code=0` 并落地非空图片/字体与配置。
- 官方歌词识别、歌词动画、TTS、转场、画面特效等曾在流水线调用，但每次新资源仍需独立套用及视觉验证。

## 不可推广的证据

help / 参数校验仅表示入口和契约；缓存目录或 lock 不是完整资源；网络规则数不是请求成功；单个资源下载成功不代表所有依赖可用；导出成功不代表字幕、字体或混音正确。

## 当前需要继续验证

- 失败字体默陌专辑手写体：查询成功，官方下载解压失败，包哈希正确；未解禁。
- 各歌词模板下载依赖后的套用与成片字形。
- 对旧流水线本地替代路径的严格官方门禁。

## 使用方法

优先通过 `scripts/official_materials.py` 在 ASCII 可写工作区联网搜索、查询及下载，保存完整证据。类型与参数以本机官方 help 为准。

逐项结果见 `official-online-verification.md`。`cli-commands.md` 和 `cli-functions.json` 可用于入口发现，`cli-status.json` 是历史参数探测记录，不再作为可用性矩阵。
