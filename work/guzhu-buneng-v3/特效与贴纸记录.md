# 《不再需要答案》特效与贴纸调整记录

成片：`fx2/render.mp4`（1280×720，29.633s，真峰值 -0.1dBFS）

## 画面特效：这次真正生效了

上一版只加了「富士影片」，它只是轻微调色，视觉上几乎看不出，等于白加。本版按歌词意境
（雨夜 / 路灯 / 回忆 / 释怀）重新选了 **3 个低强度氛围特效**：

| 特效 | 资源 ID | 挂载方式 | 覆盖 |
|---|---|---|---|
| 梦幻漏光 | 7581434656197741849 | 段特效（`video effect add`） | 8.6–29.6s |
| 细雨 | 7496779956345654552 | **全局效果轨**（`effect add`） | 8.6–29.6s |
| 婆娑光斑 | 7666032151833546008 | **全局效果轨**（`effect add`） | 8.6–29.6s |

关键点：**段特效同一时刻只保留一个**（实测连加 3 个，最终只剩最后一个），
所以其余氛围特效必须走 `draft effect add` 的**全局效果轨**才能叠加。
现在草稿里有 **2 条 effect 轨 + 1 条段引用**，抽帧可见明显的漏光、雨雾与光斑，
成片体积从 3MB 涨到 17.5MB。

## 贴纸放大：未成功，如实记录

按用户要求把贴纸调大，尝试了三条路，**都没有生效**：

1. `clip.scale` = 0.75 → 再改 1.5：两版渲染帧的 **sha256 完全相同**，说明该字段不参与渲染。
2. 官方 `draft keyframe add --seg-type sticker --animated-property scale`：
   **exitCode 2 失败**，`common_keyframes` 仍为 0。
3. 官方 `draft video scale`：历史上对 sticker 段返回 `-100110`（期望 `segment_video`）。

官方贴纸命令只有 `add` / `remove` / `translate` 三个，**没有缩放能力**（`translate` 只移动位置）。
因此本版贴纸仍是素材原始尺寸。**没有伪称已放大。**

可能的后续路径（需用户确认）：
- 请告知剪映里调整贴纸大小的具体做法/字段，我按官方通道实现；
- 或改用在素材库里**本身尺寸更大**的贴纸资源；
- 或把贴纸改为「文字贴纸」由 `draft text` 通道控制，那条通道有字号能力。
